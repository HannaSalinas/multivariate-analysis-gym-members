# Datos

`Miembros_gimnasio.xlsx` es una versión en español del **Gym Members Exercise Dataset** de Vala Khorasani, publicado en Kaggle bajo licencia [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0):
https://www.kaggle.com/datasets/valakhorasani/gym-members-exercise-dataset

Cambios respecto al original (973 registros, 15 variables): nombres de columnas traducidos al español, una columna adicional `Categoría_IMC` y 970 registros.
